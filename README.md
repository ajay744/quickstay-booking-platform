# QuickStay – Room & PG Booking System

QuickStay is a role-based web application built with Angular 16, designed to help users search and book PGs/rooms, owners to list and manage their properties, and admins to oversee the system.

This project demonstrates scalable architecture, industry coding standards, and Angular concepts like routing, modules, services, guards, and RxJS.

##  Features

###  User
- Search PGs / Rooms by city or price
- View detailed PG listings
- Send booking requests
- View booking status

###  Owner
- Add/Edit/Delete PG Listings
- View and respond to booking requests
- Manage listed properties

###  Admin
- Approve PG Listings
- Manage Users & Owners
- Basic dashboard and analytics (optional)

---

##  Tech Stack

- Angular 16
- RxJS
- SCSS
- Angular Routing & Lazy Loading
- Angular Forms (Reactive)
- Angular Material (optional)
- JSON Server or Firebase (for mock API)
